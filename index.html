잠자리 교과서 이야기책 읽어주는 AI · 레벨이 오를수록 이야기가 깊어져요

과목과 레벨을 고르세요. 6학년은 포근한 이야기로 시작하고, 그 레벨의 이야기를 모두 들으면 중1 → 중2가 차례로 열려요. 같은 주제가 점점 깊어진답니다.

교과서 기반으로 만들어야 내용이 정확하고 난이도도 딱 맞아요. 교과서 페이지를 촬영해 글자로 옮기거나 직접 타이핑해 아래에 붙여넣으면, AI가 그 내용만 가지고 잠자리 이야기로 바꿔줘요.

  1. 레벨·과목을 고르고, 교과서 내용을 붙여넣은 뒤 ‘지시문 복사’를 누르세요.
  2. 복사한 지시문을 GPT나 Claude 새 대화창에 붙여넣고 이야기를 받으세요.
  3. 받은 이야기를 아래에 붙여넣고 ‘이 이야기 듣기’를 누르세요.
🌙 브라우저 내장 음성을 사용해요. Chrome 또는 Edge에서 가장 잘 작동합니다.
진행 상황은 이번 세션 동안만 기억해요(창을 닫으면 초기화).

🎙️ 자연 목소리 설정

ChatGPT처럼 자연스러운 목소리로 읽으려면 OpenAI API 키가 필요해요. 키는 이 기기(브라우저)에만 저장되고 외부로 보내지 않아요. 사용한 만큼 소액 요금이 들 수 있어요.

키 발급 — OpenAI: platform.openai.com → API keys. Gemini: aistudio.google.com → 'Get API key'. 키는 이 기기에만 저장되고, 남에게 보여주지 마세요.
